# ButlerCRM capture provenance

Captured September 5, 2026 from the actual Phoenix/LiveView application in
an isolated local environment. A disposable PostgreSQL database was migrated
and populated through existing fixture APIs. All names, tasks, comments and
project records shown are fictional and visibly labeled DEMO.

Email, external workers, AI calls and Jarvis integration were disabled.
No production records, sessions or credentials were used in these captures.

- `butler-board-desktop.jpg`: actual work board and full application shell.
- `butler-task-detail.jpg`: actual task detail with fictional subtask/comment.
- `butler-task-mobile-420.jpg`: the same task at a mobile viewport.

These images demonstrate application rendering and the observed local UI
workflow. They do not establish production throughput, adoption, customer
outcomes or the execution of integrations shown elsewhere in navigation.
Original screenshots are retained without cropping or compositing.
