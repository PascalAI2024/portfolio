# Overwatch capture provenance

Captured September 5, 2026 in an isolated local UI harness. The harness renders
the released MissionControlPage, QueuePage, CommandDeckShell, Surface,
DecisionDeck, Fleet, EvidencePane and DiffBlock components. Backend loader and
authentication imports are replaced by local fixtures; mutations are disabled.

Fictional site names and proposals are explicitly labeled DEMO. The overview
shows unmeasured sites and zero runs/spend rather than invented performance.
Queue selection was checked between the metadata and keyword proposals.

- `overwatch-mission-desktop.jpg`: full Mission Control route and shell.
- `overwatch-queue-detail.jpg`: native queue selection and before/after detail.
- `overwatch-queue-mobile-420.jpg`: the queue at a420px mobile viewport.

These are actual interface components, not hand-drawn dashboard mockups. They
are also not authenticated production-backend evidence. No customer records,
credentials, provider configuration or production sessions are included.
Screenshots remain uncropped originals.
