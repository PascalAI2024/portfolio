## Format

Each study follows: **brief → constraints → decisive move → system shape →
public proof → outcome or learning → boundary**.

## Editorial rules

- Lead with the work, not the tool list.
- Prefer attributable public proof over anonymous superlatives.
- Name a client only with explicit permission.
- Use redacted, synthetic, or recreated examples when a real artifact is private.
- Keep implementation detail useful but never reusable as an access path or a
  private operating manual.

## Pipeline

`candidate` → `clearance` → `draft` → `visual proof` → `review` → `published`

Nothing moves to `published` until the public-safe review is complete.
