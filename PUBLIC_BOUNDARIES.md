# Public Boundaries

This repository shows selected work and the reasoning behind it. It does not
publish client data, credentials, private source code, production topology,
security controls, internal prompts, automation recipes, access paths, or
unapproved brand material.

For each story, the standard is simple: show the problem, the decision, and the
evidence; omit the machinery that would expose a client or make private work
reusable without context.

Claims are published only when they are attributable to a public artifact or a
public-safe, reviewable description. When evidence is private, that is stated.
